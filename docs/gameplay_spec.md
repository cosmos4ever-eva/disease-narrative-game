# v0.1 游戏规格

## 1. 产品目标

本项目是一款单人悬疑疫病推理游戏。玩家面对五个拥有秘密、独立记忆和动态关系的 NPC Agent，通过调查、对话、帮助、欺骗、指控和隔离，确认污染源并控制疫病扩散。

核心体验是：NPC 会记住玩家的选择，并在之后改变语气、信任、线索分享和行动。

## 2. 玩家可做的事

玩家可以：

- 询问 NPC
- 调查场景
- 移动场景
- 帮助 NPC
- 欺骗 NPC
- 指控 NPC
- 隔离 NPC
- 封存污染源

玩家可以自由输入问题，同时看到系统推荐问题。自由输入只能影响已有的意图、Claim 或普通对话，不能创造新的客观事实。

## 3. 时间与行动力

游戏采用白天/夜晚双阶段。

### 白天

- 每天拥有 3 点行动力。
- 询问、调查、帮助、欺骗、指控和隔离均消耗 1 点行动力。
- 移动不消耗行动力，但必须沿着地图道路前往相邻场景。
- 查看地图、日志、证据和假设不消耗行动力。
- 行动力耗尽后进入夜晚。
- 玩家可以提前结束白天。

### 夜晚

夜晚依次执行：

1. 每个 NPC 最多执行一次自主行动。
2. 满足条件的 NPC 进行有限交流。
3. 执行感染传播和状态升级。
4. 触发夜间事件。
5. 更新 NPC 记忆、关系和日志。
6. 进入下一天白天。

游戏最多持续 7 天。达到终局条件时立即进入结局。

## 4. 场景与互动范围

玩家只能与当前场景中的 NPC 互动。移动消耗 1 点行动力。场景位置同时影响：

- 可调查的证据
- 可访问的 NPC
- 感染传播
- NPC-NPC 交流
- 夜间自主行动

## 5. 调查与线索

调查采用两层结构：

```text
调查场景 -> 获得观察证据 -> 组合证据 -> 验证 Claim
```

调查不会直接把完整真相展示给玩家。系统自动记录证据和已验证 Claim；玩家可以将证据标记为支持、怀疑或无关，并创建自己的假设。

假设不会直接改变游戏状态，只有正式指控、隔离或封存行动会产生规则后果。

## 6. 帮助与欺骗

帮助任务由规则系统预设，Agent 根据人格、记忆和目标个性化表达。完成帮助会改变信任和记忆，并可能解锁额外线索。

玩家可以自由输入欺骗内容。系统必须将内容映射到已有 Claim 或误导 Claim；无法映射时只能作为普通对话。NPC 根据自身记忆、信任度和性格判断是否相信。

## 7. 指控与隔离

玩家随时可以正式指控 NPC，消耗 1 点行动力并立即影响关系和后续流程。错误指控可能导致误判结局，但不会自动删除 NPC。

隔离可以停止同场景传播，但不能治愈感染，也不能阻止 NPC 的病程继续。

## 8. 感染与结局

玩家看不到真实感染状态，只能观察症状、行为、接触记录和 NPC 证词。开发者模式可以查看真实状态。

### 成功条件

```text
确认污染源 + 找到并封存黑色石匣 + 感染仍处于可控范围
```

封存源头后进入短暂结局收束阶段，展示 NPC 对玩家的记忆、关系变化、感染结果和关键选择。

### 失败条件

- 所有 NPC 进入潜伏或确认感染
- 达到第 7 天仍未封存源头
- 错误处理污染物
- 错误指控并驱逐关键角色

## 9. NPC 生存与治疗

v0.1 不允许 NPC 永久死亡。NPC 可以被隔离、失联或进入失控状态。

v0.1 不提供治愈机制。封存源头只能阻止新增感染，不能自动治愈已有感染。

## 10. 主线与支线

主线固定为：

```text
发现异常 -> 追踪污染源 -> 确认传播机制 -> 找到黑色石匣 -> 封存源头
```

支线由玩家行为和 Agent 关系动态决定，包括帮助、误导、NPC 冲突、额外证词和错过的线索。

## 11. 结局报告

不设置单一总分。结局阶段展示多维案件报告：

- 调查完整度
- 源头判断准确度
- 感染控制程度
- NPC 信任程度
- 错过的关键线索
- 玩家行为风格

## 12. 序章剧情节点

序章从第 1 天白天的营地开始。玩家首先看到 Wilson 实验台中的黑色孢子躲避光线。此时只开放营地，不开放森林边缘、墓地、遗迹小路和隔离区。

玩家可以选择三个行动：

1. 询问 Wilson：获得黑色孢子异常和实验线索。
2. 调查实验台：获得“黑色孢子会躲避光线”的观察证据。
3. 询问 Wolfgang：获得指向 Willow 的不完整目击证词。

完成其中任意两个有效行动后，解锁森林边缘和墓地，并解锁 Willow 与 Wendy。行动顺序不固定，但不同顺序会影响 NPC 记忆和后续对话。

### Wilson 的序章定位

Wilson 谨慎合作，承认孢子异常，但不直接指认 Maxwell。他会要求玩家先观察实验台和样本。

### Wolfgang 的序章定位

Wolfgang 处于潜伏感染状态，但玩家看不到真实感染状态。他只表现为恐惧，不出现明确身体症状。他会把嫌疑引向 Willow，但证词混合了不完整目击、错误认知和感染后的错误传播。

Wolfgang 的不可靠性不通过系统直接告知玩家，而通过现场证据、时间线和后续证词矛盾逐步揭露。
