# v0.1 Agent 契约

## 1. Agent 能力

每个 NPC Agent 拥有：

- 固定核心人格
- 动态心理状态
- 私密记忆
- 对其他 NPC 和玩家的关系
- 当前目标和备用目标
- 有限行动白名单

第一版保留五个 Agent：Wilson、Willow、Wendy、Wolfgang、Maxwell。

## 2. 人格规则

核心人格不会被 Agent 完全改写。信任、恐惧、怀疑、情绪、合作意愿和当前目标可以动态变化。

人格只能影响表达和行动倾向，不能修改客观 Claim、感染真值或结局条件。

## 3. 记忆规则

记忆只在单局内保存，包含：

- 事件记忆
- 事实认知
- 关系记忆
- 情绪记忆
- 传闻记忆

每条记忆至少包含来源、时间、重要性、可信度、可见范围和检索标签。

重要记忆保留，普通记忆可以弱化；不同来源产生冲突时保留多个版本，不强制生成唯一真相。Agent 可以表达不确定性。

每个 NPC 只能读取自己的记忆。NPC 只会获得其他角色实际说出、公开分享或亲眼观察到的信息，不会自动读取其他 Agent 的完整记忆。

## 4. 行动白名单

Agent 只能从以下行动中选择：

```text
answer
evade
lie
reveal
accuse
request_help
move
hide_evidence
confess
```

行动必须经过规则系统校验。Agent 不能：

- 创造新角色
- 创造新的客观线索
- 修改感染状态
- 修改 Claim 真值
- 直接结束游戏
- 绕过场景和行动力限制

## 5. NPC 主动互动

NPC 可以在白天有限主动找玩家。每个 NPC 每天最多主动一次，不消耗玩家行动力。

玩家可以：

- 接受
- 拒绝
- 追问

接受任务或跟随 NPC 行动消耗 1 点行动力。拒绝会被 NPC 记住，并可能改变信任。

## 6. NPC-NPC 交流

夜间允许有限 NPC-NPC 交流。玩家看不到完整私聊，只能通过第二天的行为变化、关系变化、证词和间接线索推断。开发者模式可以查看完整交流日志。

## 7. 对话生成流程

```text
当前 GameState
 -> 玩家意图
 -> 相关记忆检索
 -> 当前目标和关系
 -> 选择行动白名单动作
 -> 过滤允许表达的 Claim
 -> 生成符合人格的台词
 -> 写入本轮记忆
```

Agent 输出必须是结构化对象：

```json
{
  "action": "evade",
  "revealed_claims": [],
  "trust_delta": -3,
  "memory_updates": [],
  "dialogue": "你似乎已经决定相信那些灰烬了。"
}
```

## 8. Mock 与真实模型

Mock Agent 是默认实现，确保没有 API Key 时项目仍然可以运行。真实 LLM 只能替换 Agent 的决策和表达层，不能直接写入 GameState。
