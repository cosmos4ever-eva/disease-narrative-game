# 场景贴图

将正式场景图片放在这里：

```text
camp.png
forest_edge.png
graveyard.png
ruins_path.png
isolated_camp.png
```

建议规格：

- 横向构图，16:9 或接近 16:9
- 不在图片内写标题和按钮文字
- 五张图使用统一视角、光照和色彩风格
- 预留中间区域给 NPC、证据和对话层
- 第一版可以使用 1600x900 PNG
# 场景图片

场景卡片和顶部场景展示会按场景 ID 自动读取同名 PNG：

- `camp.png`：营地
- `forest_edge.png`：森林边缘
- `graveyard.png`：墓地
- `ruins_path.png`：遗迹小路
- `isolated_camp.png`：隔离区

图片放在本目录后，重新运行 Godot 即可生效。尚未提供图片的场景会继续显示默认图标。
